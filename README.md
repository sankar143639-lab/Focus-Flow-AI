# Focus Flow AI 🎓⚡

Focus Flow AI is an on-device productivity and study assistant optimized for Snapdragon-powered HP PCs.

## Features
- Offline PDF Document Q&A
- Automated Flashcard Generation
- NPU Acceleration via Qualcomm AI Hub models & QNN Execution Provider

## Setup
1. Clone the repository: `git clone https://github.com/your-username/Focus-Flow-AI.git`
2. Install requirements: `pip install -r requirements.txt`
3. Run app: `python app.py`
